# Karabiner keyboard setup

Developer keyboard bindings for macOS, applied to all keyboards.

## Bindings

- Tap Caps Lock: Escape
- Hold Caps Lock: Left Control
- Shift + Caps Lock: real Caps Lock
- Tap Right Command: Right Command
- Hold Right Command: navigation and Raycast layer
  - `h/j/k/l`: left/down/up/right arrows
  - `b/w`: previous/next word
  - `a/e`: start/end of line
  - `v`: emits Hyper + V for Clipboard History
  - `i`: emits Hyper + I for Emoji & Symbols
  - Left/right arrows: emits Hyper + Left/Right Arrow for window halves
  - `=` / `-` / Return: emits Hyper window-management shortcuts
  - `t`: emits Hyper + T for WezTerm
  - `c`: emits Hyper + C for Cursor
  - `g`: emits Hyper + G for Google/browser
  - Shift remains available for text selection
- Left Command remains the normal Mac shortcut key.

Hyper means Control + Option + Shift + Command. The timeout for Caps Lock and Right Command is 250 ms.

## Raycast setup

- Set **Hyper Key** to none (`-`)
- Enable **Replace occurrences of Control + Option + Shift + Command with Hyper**
- Assign Raycast commands to the Hyper shortcuts listed above
- Emoji uses Hyper + I because Right Command + E is reserved for end-of-line navigation

Raycast shortcuts are generated by Karabiner, so they work consistently across the MacBook keyboard and Keychron K3 after reconnecting.

## Files

- `karabiner.json`: active profile and enabled rule
- `assets/complex_modifications/developer_nav.json`: reusable complex modification
- `automatic_backups/`: local backups, do not copy between Macs

## Validation

```bash
"/Library/Application Support/org.pqrs/Karabiner-Elements/bin/karabiner_cli" \
  --lint-complex-modifications \
  ~/.config/karabiner/assets/complex_modifications/developer_nav.json
```
