# Corne layout

Vial layout for the 4x6 Corne. Import `corne.vil` with **File → Load saved layout...** while the keyboard is plugged in. Vial does not read this folder on its own.

## Thumbs

Left, outer to inner: Option, Command, Enter.

Right, inner to outer: Space, hold for layer 1, Hyper.

Hyper is Control + Option + Shift + Command, the same chord Raycast uses. Left Command stays Command. Semicolon is a normal key.

## Layer 1

Hold the middle right thumb.

- `h j k l`: arrows
- `q w e r t`: `` ` - = [ ] ``, and `a` is `\`
- Shift types the upper symbol
- `z x`: display brightness down, display brightness up
- `n m ,`: mute, volume down, volume up. Volume down and up sit under `j` and `k`
- Number row: F1 through F10. Up and Down are F11 and F12

Hold Option with an arrow for the previous or next word. Hold Option and press Backspace to delete the previous word.

Layers 2 through 5 are transparent.
